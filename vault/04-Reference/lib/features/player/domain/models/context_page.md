## Executive Summary
`context_page.dart` is a core domain entity replicating Spotify's `com.spotify.player.model.ContextPage`. It encapsulates a discrete page of context tracks along with URL references (`pageUrl`, `nextPageUrl`), page-level metadata, and an `isLoading` status flag.

**Primary Architecture Role**: Domain Model / Value Object
